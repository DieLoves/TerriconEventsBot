# Полировка пользовательского маршрута (2026-10-26)

Статус: завершён и выкачен 2026-10-26 (`d2ee176`, `a6c3531`).

Основание: аудит маршрута `/start` → onboarding → меню → каталог → карточка →
подписки → настройки → обратная связь → удаление данных → уведомления.
Решения пользователя: каталог открывается сразу списком; умеренные эмодзи на
кнопках меню и навигации.

## Дефекты

1. `/start` и текстовые сообщения редактируют старый экран выше по истории —
   внизу чата ничего не появляется. Экран, вызванный сообщением, отправляется
   заново (`ScreenRenderer.render(..., fresh=True)`), старый удаляется.
2. На одном экране две кнопки «Назад» с разным смыслом (страницы списка/раздел,
   страницы описания/карточка, соседнее событие). Пагинация — `◀️ n/N ▶️`,
   возврат — явные «К списку», «К мероприятию», «В меню».
3. `/start` во время мастера обратной связи не отменял черновик.
4. После удаления данных — тупиковая кнопка «Назад».

## Маршрут каталога

«Мероприятия» в меню сразу открывает список с сохранённым состоянием
(страница 1; по умолчанию — актуальные, все категории). В списке:
сводка активных фильтров, `🗂 Категория`, `🔎 Фильтры`, переключатель
`Актуальные ⇄ Архив`, `🏠 В меню`; при пустом результате с непустыми
фильтрами — «Сбросить фильтры». Категория — фильтр, её смена не сбрасывает
формат и язык; смена раздела сбрасывает только период.

## Тексты и оформление

- Двуязычный выбор языка при первом запуске; intro перечисляет возможности.
- Меню 1+2+2 с иконками; подзаголовок.
- Подсказки на экранах подписок (дайджест, тихие часы), обратной связи,
  настроек; экран приватности описывает хранимые данные.
- Деструктивное подтверждение «Да, удалить»; отправка обращения «Отправить».
- Ответ администратора подсказывает, что можно ответить сообщением.
- Дайджест: иконки заголовков, даты и ссылки (plain text, без HTML).
- Команда `/start` публикуется в меню команд Telegram (RU и `kk`).

## Проверка

Ruff, format, mypy, полный pytest с PostgreSQL; спецификация обновляется в
разделе «Навигация/Каталог».

Итог: 290 passed на одноразовом PostgreSQL 17 (+10 тестов маршрута, `fresh`-рендера,
UTF-16-лимита дайджеста и меню команд); ruff/format/mypy/lock clean. Дополнительно:
длина дайджеста считается в UTF-16 единицах Telegram (эмодзи = 2). Новые KZ-строки
переведены Claude и требуют проверки пользователем.
